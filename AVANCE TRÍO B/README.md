# Avance Trío B

Carpeta con el avance del Trío B (Nahuel, José y Xavier): backend, API, autenticación e integración de la base de datos del Sistema de Parqueo.

## Tecnologías
- Backend: Node.js + Express
- API: REST + JSON
- Base de datos: PostgreSQL
- Autenticación: JWT + bcrypt
- Pruebas de API: Postman
